# Lehi 31 Callings — downloads

**Public output repo.** Nothing here is authored by hand except `index.html`.

- GitHub Pages serves `index.html` as the download page.
- Each app version is a **GitHub Release** on this repo with `lehi31-callings.apk` attached; the page links to `releases/latest/download/lehi31-callings.apk` so it never goes stale.
- Releases are cut from the private source repo (`app`) with its `scripts/publish.sh`.

Source, issues, and history live in the private `app` repo.
